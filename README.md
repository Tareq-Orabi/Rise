# Rise — مساحة Octagram الداخلية لعام 2027

افتح `dist/index.html` لعرض لوحة الخطة وقراءة الخطة العامة وخطط الفريق. الملف مستقل ويضم الخط والشعار وملفات PDF الثمانية، ويعمل دون إنترنت.

## الواجهة الإدارية للمطالعة

- موقع ثابت دون Backend أو حسابات أو قاعدة بيانات؛ لا توجد آليات لتعديل الحالات أو الملاحظات.
- قائمة جانبية للمشاريع والمهام والجدول التنفيذي والفريق ومكتبة الوثائق.
- بحث شامل في 102 قسم، وتصفية المهام حسب المشروع والمسؤول والفترة.
- جميع الأرقام أهداف أو أعداد مستخرجة من الخطة، وليست نسب إنجاز فعلية.
- مشروع OctaCare مضاف بوثيقته الكاملة: دراسة أبريل–يونيو، تطوير يوليو–سبتمبر وتشغيل أكتوبر–ديسمبر مشروطان بقرار يونيو.
- تصحيح الاسم إلى زيد التايه في وثيقة OctaCare وتحديث مهام الأعضاء والخطة العامة.

## التحديث الحالي

- ملكية كود MedClub محسومة لصالح Octagram؛ الفحص المطلوب تقني ولا يتضمن مراجعة ملكية إضافية.
- تنفيذ برنامج Full Product V1 من 1 ديسمبر 2026 إلى 28 فبراير 2027، وفق المراحل الست في الوثيقة؛ مارس للاستقرار وتجهيز التجربة.
- نطاق P0 ملزم: يشمل THINK وTech Path وCode Runner. تبقى إضافات P1 بقرار صريح وP2 للتوسع اللاحق.
- وثيقتا المنتج متاحتان من المشاريع ومكتبة الوثائق. المصدران المحرران في `src/product-requirements.txt` و`src/octacare-requirements.txt`.

- إعادة تحرير الخطة بأسلوب رسمي يحدد الأهداف والمخرجات والقرارات، بدل الخطاب المحكي أو المباشر للأشخاص.
- تصحيح الاسم إلى **زيد التايه** في الواجهة ومحتوى الخطط وملفات PDF.
- تنظيم 71 مهمة تنفيذية، مع خطط الشركة والفريق ووثيقة المنتج التفصيلية، باستخدام حقول واضحة للمخرج المطلوب ومعايير القبول والاعتماديات، والموعد المحدد عند وجوده.
- اعتماد خط **Cairo** المضمّن محليًا، وتحسين التباعد والتمييز بين العناوين والنصوص والجداول.
- تحديث ملفات PDF الثمانية وإعادة تضمينها في التطبيق. الأرقام والأهداف التشغيلية بقيت ضمن إطار الخطة ومقترحاتها، دون تحويلها إلى نتائج محققة.

## التشغيل والتطوير

يتطلب المشروع Node.js 20 أو أحدث.

```sh
npm ci
npm run dev
```

لبناء الملف المستقل:

```sh
npm run build
```

## تعديل المحتوى

| الملف | الغرض |
| --- | --- |
| `src/plan-content.js` | محتوى الخطط والأهداف والمهام والجداول |
| `src/App.jsx` | الواجهة الإدارية والبحث والتنقل والتصفية |
| `src/management.js` | فهرسة المهام والمراحل وأقسام البحث |
| `src/Reader.jsx` | عرض النصوص والجداول وبطاقات المهام |
| `src/app.css` و`src/reader.css` | الواجهة والتجاوب وأنماط الطباعة |
| `src/fonts.css` و`assets/` | تعريف Cairo وملفات الخط والشعار |

تستخدم المهمة المنظمة النوع `task` مع الحقول `title` و`owner` و`deliverable` و`acceptance`، و`dependencies` و`deadline` عند الحاجة. معايير القبول والاعتماديات قوائم مستقلة لتسهيل القراءة والمراجعة. يعتمد كل قسم فصلي موعد مراجعة؛ ولا تُختلق مواعيد جزئية غير معتمدة.

## إعادة إنتاج ملفات PDF

يتوفر مساران للتصدير؛ يقرأ كلاهما المحتوى نفسه من `src/plan-content.js`.

### التصدير عبر Python

استخدم هذا المسار لإعادة إنتاج تصميم ملفات PDF المرفقة. يتطلب Python 3.10 أو أحدث والحزم التالية:

```sh
python3 -m pip install reportlab fonttools arabic-reshaper python-bidi
npm run pdf:portable
node scripts/embed-pdfs.mjs
npm run build
```

ولتحديث خطة واحدة:

```sh
python3 scripts/export-pdfs.py zaid-backend
node scripts/embed-pdfs.mjs
npm run build
```

### التصدير من واجهة الطباعة

```sh
npm run release
```

يستخدم هذا المسار Chrome أو Chromium وPlaywright لطباعة صفحات React. يمكن تحديد المتصفح عبر `CHROMIUM_PATH`. قد يختلف توزيع الصفحات عن تصدير Python. يعرض تذييل نسخة الطباعة رقم القسم، بينما تستخدم ملفات Python ترقيم الصفحات الفعلي.

## التحقق والترخيص

تم بناء التطبيق، وتوليد ملفات PDF، ومراجعة صفحاتها بصريًا للتحقق من العربية والجداول والتقسيم. ترخيص Cairo مفتوح ومرفق في `licenses/Cairo-OFL.txt`. تراخيص الحزم وبقية الأصول محفوظة في `licenses/`.

## النشر على GitHub Pages

المستودع: https://github.com/Tareq-Orabi/Rise

عنوان الموقع: https://tareq-orabi.github.io/Rise/

ينفذ `.github/workflows/deploy-pages.yml` تثبيت الاعتماديات، وإعادة تضمين ملفات PDF، وبناء `dist/index.html`، ثم النشر عند تحديث `main`. يمكن تشغيله يدويًا من Actions. يستخدم الموقع مسارات Hash لتعمل صفحات المشاريع والوثائق مباشرة تحت `/Rise/`.

النسخة المنشورة عامة ومخصصة للمطالعة، دون حسابات أو Backend أو حفظ بيانات مستخدمين. تتضمن الوثائق المدرجة في المشروع نفسه.

## دليل الخدمات

يمكن تبديل العرض بين الوضع الفاتح والداكن من شريط الموقع؛ يُحفظ الاختيار في المتصفح، وتظل الطباعة فاتحة.

قسم `#/company/services` يعرض الخدمات الهندسية الثماني فقط، دون الأعمال السابقة أو بيانات التواصل أو بقية محتوى العرض التجاري. يمكن الوصول إليه من القائمة الجانبية والبحث ومكتبة الوثائق. ملف `pdf/commercial.pdf` هو نسخة من دليل الخدمات فقط؛ أزيل ملف العرض التجاري الأصلي من النسخة الحالية للمشروع.
